_Yifan Kang, Bowen Yu, Hanhong Zhao_

An AI meeting agent that joins Zoom as a participant, listens along, and executes tasks while the conversation keeps going — drafting documents, researching alternatives, reviewing code, and pulling out action items. A voice agent (OpenAI Realtime API + Deepgram) decides in real time whether to answer immediately or hand the work off to a background worker (Devin / Codex CLI), so the meeting never blocks on the agent. Results stream into a shared workspace. Built at HackMIT.
