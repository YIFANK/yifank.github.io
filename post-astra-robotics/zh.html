后 Astra 时代的机器人学

前沿编程 agent 现在领跑一个机器人操作基准。谈谈为什么会这样，以及这给机器人研究留下了什么。

这篇文章是我在奥斯汀参加 CoRL 2026 时开始写的。作为第一次参加 CoRL 的本科生，我花了很多时间听博士生和资深研究者之间的讨论。

11 月 9 日是主会第一天，Jim Fan 的主旨演讲里有一页讲 GPT-6 Astra，不到半小时，这一段的视频就在 X 上传开了。CoRL 今年也第一次征集 late-breaking results，agentic robotics 是两个主题之一。同一天，Anthropic 公布 Claude Fable 5.2 在 RoboDojo Sim 上拿到 64.9%。有人开始说，苦涩的教训要轮到机器人学了。

不管大家做的是机器人学的哪个方向，agentic robotics 都成了房间里的大象，一个我们没法忽视的问题。

Fable 5.2 的这个分数排在 RoboDojo 排行榜上所有学习型策略前面（图 1）。Anthropic 没有公布逐任务的结果，所以这篇文章大部分用的是我能找到的最接近的公开数据。Agent as Policy（AGP）把 GPT-6 Astra 放进一个编程 agent 框架里运行，公开了全部 2,100 个 RoboDojo episode，包括日志和视频。它的得分是 63.6，和 Fable 5.2 差不多。

这个能力确实很厉害，但我不认为现在可以说机器人学已经“解决”了，也不觉得它是凭空冒出来的。我看到的兴奋里，大多带着一种意外感。但我觉得，从这个基准测的是什么、从机器人学本来就会做什么出发，这个结果几乎是顺理成章的。把原因想清楚，也能看出还有哪些事可做。

§1操作基准现在考的是大脑

新一代的操作基准考的不只是运动技能。这篇文章主要用到的 RoboDojo 就是一个好例子。在它的 42 个仿真任务里，机器人要把数字积木摆成正确的等式、下井字棋，或者把积木换来换去，同时记住哪个是哪个。

在解等式任务里，机器人要读出数字、算出答案、决定哪块积木放哪里，然后找到这些积木并把它们挪过去。只有最后这一步真正和运动控制有关。

如今的 VLA 已经学到了很厉害的动作分布，能叠衣服，能打开没见过的抽屉。它们缺的是类似大脑的东西。目前大多数 VLA 把最近的观测和一条指令映射成下一段动作。有些加了记忆或高层规划模块，但它们往往缺少编程 agent 天生就有的那种显式、持久、可编辑的任务状态：一个存计划、追踪隐藏状态、发现算错的地方。这类任务测的主要就是缺的这一块，所以几乎说明不了一个策略的“手”好不好。

前沿 LLM 是从另一头接近这些任务的。推理、记忆和把任务拆成步骤，它本来就擅长；它需要的是把决定变成动作的办法。

§2老派机器人学的复兴

在深度学习之前，机器人学就已经有了这些任务需要的大部分零件。给定物体位姿，可以采样抓取，解手臂的逆运动学，规划一条无碰撞路径，再用反馈控制器去跟踪。这些方法大多是人手设计的，对不同物体、不同手臂都能用。

它们也能做长任务。1971 年，Shakey 就在用 STRIPS 规划多步动作。1980 年代末，Lozano-Pérez 的 Handey 系统能根据场景的几何模型规划抓取放置动作，包括抓取本身。RRT（LaValle，1998）让高维手臂的运动规划变得实用，任务与运动规划（Kaelbling 和 Lozano-Pérez，2011，以及其他很多工作）把符号规划和几何规划串成很多步。

瓶颈在人工工程。每来一个新任务，都得有人给场景建模、手写状态机：先拿哪个物体、放到哪里、怎样算完成、抓滑了怎么办。为一套环境搭好的系统，换到下一套环境通常还得再做工程。这份成本是这个领域转向端到端学习的一个重要原因，端到端学习用数据取代了手写的结构。

编程 agent 把这份工程的大部分接了过去。它看场景，写一段调用感知、逆运动学和规划器的程序，运行，再看一眼，出了问题就改程序（图 4）。VLA 得从数据里学会失败恢复，而 agent 只要检查自己的结果，就能得到一个基础版本。

Ken Goldberg 九月在一篇题为《Goosebumps》的文章里提出了类似的观点，他把 agentic robotics 称作“机器人学两种主流文化之间的第三条路”。我是从学习这一派进入机器人学的，所以这提醒了我另一派至今还在做多少事。

来看一个 RoboDojo 上的例子。AGP 公开了每个 episode 的完整事件日志，只有模型的私有推理不在里面。图 5 回放了其中一个，解等式任务，agent 用十二次工具调用完成。

这里的每条指令都是模型自己推理出来的，但几乎都不是关节指令：全部 2,100 个 episode 里，它只发出了一百次左右关节空间的动作，相比之下末端目标位姿约 50,000 个。它用像素和位姿来思考，关节留给逆运动学和规划器。在图 5 里，松手之前，也就是唯一无法撤回的那一步，它又测了一遍，并绕开了一个它不信任的深度估计。整个数据集里，大约每五次工具调用就有一次报告了需要 agent 处理的失败。

AGP 的提示词里每个任务还带了几条人写的提示，比如拿螺母之前夹爪该张多大，所以一部分人工工程仍然在回路里，只不过是用文字而不是代码写的。

同一套工具也解释了 agent 在哪里失败。在图 2 的“手”类任务上，插钥匙和装鸡蛋托都是 0%，插充电器是 4%。这些任务依赖相机看不到的接触力，而老工具在接触上也从来不强。

§3以秒为单位思考

我最常听到的反对意见和时间有关。在 AGP 的日志里，一个 episode 要花 8.6 分钟，机器人实际只动了 24.5 秒，其中大约六分钟是模型在思考，而不是仿真或规划（图 7）。光是模型本身，就得快大约 14 倍才能跟上机器人。

更快的芯片、更小的模型，以及用更少 token 得到同样答案的模型，都在缩小这个差距，合起来大概每年 3–15 倍。照这个速度，agent 会在 2027 年底到 2029 年初之间追上机器人。

即便到了那时，仍有一些推理留在关键路径上，因为从错误中恢复，就得看结果、再决定下一步。Brooks 在 1986 年主张用不等规划器的快速反应层，之后的三层架构（Gat，1998）把一个慢的审议层放在技能调度层和快速控制器之上。agent 正好放在最上面这一层：技能执行时它在思考，技能出岔子时再介入。

NVIDIA 同一天在 CoRL 上发布的 GR00T 2 就是这样搭的。单独运行时，它在 RoboDojo 上的成功率是 35.5%。加上强化学习后训练，再作为工具交给一个前沿 agent 调用，由 agent 规划任务、盯着进度、用代码修复失败，它达到 75.8%，是目前报告的最高分，不过只在 RoboDojo 三组官方布局中的一组上测过。在真机上，同样的分工把三个杂乱场景下的装配任务从 100 次里成功 71–84 次提高到 97–98 次。

速度对部署也非常重要。如果小模型也有同样的推理能力，这类 agent 就会便宜、快到可以在真实机器人上跑，单这一点就会改变机器人的部署方式。

§4我们可以做什么

通用机器人最终的解法会是什么，很难预测。高层推理正在变成可以从 API 拿到的东西，这去掉了一类遥操作数据本来就解决不好的问题：算术、记忆、任务分解，以及知道充电器是干什么用的。还不清楚的是 agentic robotics 的边界在哪里。如果它今天做不了接触丰富、需要灵巧的任务，根本原因是什么？是接口吗，agent 拿到的是图像和位姿，没有力？是速度吗？还是更大的规模就能解决？下面是我认为还没解决的几个问题。

在机器人学里，一个任务只有成功率非常高才算解决，而且还需要反应速度和灵巧性。LLM 要怎样扩展才能解决所有这些问题，我现在还不清楚。所以即使我们相信 LLM 是最终的解法，研究怎样让 LLM 在机器人任务上的训练可以规模化，也许是值得的。

不管怎样，我觉得机器人学研究者现在可以做比以往任何时候都更有野心的问题。直到最近，一个项目通常得在“大脑”和“手”之间选一个：规划器在简化的世界里做长任务，学到的策略做叠衣服、开抽屉这样的短动作技能。现在推理可以从 API 拿到，我们可以去做两者都需要的任务，比如照着说明书组装家具、在一个没见过的厨房里按菜谱做饭，或者修一台机器。这些任务的计划很长，难的步骤又都需要大量接触。它们也正是在实验室之外真正有用的任务。
